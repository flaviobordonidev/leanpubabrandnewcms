# <a name="top"></a> Installiamo Neovim

Neovim è un editor di testo / IDE che sostituirà VisualStudio code.

TJ DeVries

## Installiamo nVim via brew on macOS

Per installare NeoVim facciamo quanto indicato nel sito ufficiale

- [neovim.io](https://neovim.io/)
- [github: neovim - install](https://github.com/neovim/neovim/blob/master/INSTALL.md)

Ossia usiamo brew:

```shell
❯ brew install neovim
```


## Entriamo in nVim


```shell
❯ nvim
```

Dentro nvim 

- eseguiamo il comando `:checkhealth`
  questo ci fa vedere lo stato di salute della nostra installazione con: OK, WARNING. ERROR
  nel mio caso non ho ERROR ma ho qualche WARNING che risolverò più avanti (aiutandomi con l'intelligenza artificiale Chat GPT ^_^)
- Per uscire `:q`
