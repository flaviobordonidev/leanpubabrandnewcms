# <a name="top"></a> Applicazione per mostrare bootstrap [25/04/17]

Creiamo una nuova applicazione su cui installeremo bootstrap e proveremo alcuni dei suoi componenti.


## L'applicazione per Boot Strap

Creiamo la nuova applicazione "bootstrap_app" nella cartella `ror` che abbiamo dedicato ai progetti di Ruby on Rails nel mio profilo utente.
Creiamo un'applicazione normalmente SENZA aggiungere opzioni per bootstrap tipo `-c bootstrap`.
Apriamo il terminale.

```shell
❯ cd /Users/fb/ror
❯ rails new bootstrap_app
❯ cd bootstrap_app/
```
