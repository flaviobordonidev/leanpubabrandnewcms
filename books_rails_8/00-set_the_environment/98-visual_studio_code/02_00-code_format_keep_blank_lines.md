# <a name="top"></a> Lasciamo le linee vuote

Nel codice è per me è utile lasciare una linea vuota di tanto in tanto per rendere più leggibile il codice.
Visual Studio Code di default rimuove tutte le linee vuote quando salviamo.


## Lasciare le linee vuote

Si può impostare quante linee vuote vogliamo che vscode lascia quando salviamo andando su:

Code --> Settings... --> Settings

Cerchiamo per: `blank line`

Tra le risposte ci apparirà anche `Keep blank lines` con un valore da impostare che di default è a `0` e quindi non lascia nessuna linea vuota. Lo cambiamo a `1` così se nel codice c'è una sola linea vuota la lascia stare.
